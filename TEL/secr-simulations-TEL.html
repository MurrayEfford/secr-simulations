Telemetry marking

These simulations test a MLE implementation of the 1-step method of Whittington et al. (2025a).

Problem description

It has been generally recognised that spatial mark–resight studies require either data on the initial deployment of marks, allowing the spatial distribution of marked animals to be modelled, or strong assumptions about the distribution (e.g. spatially uniform) (Royle et al. 2014, Efford and Hunter 2018).

However, the papers of Margenau et al. (2022) and Whittington et al. (2025a) pointed to a way of analysing camera data for collared animals that is not prone to bias from unmodelled deployment of collars. They recognised that detection parameters (e.g. \(\lambda_0\), \(\sigma\)) may be estimated from the collared animals alone. Combining the detection parameter estimates with observed counts in either a 2-stage- (Margenau et al. 2022) or 1-stage-process (Whittington et al. 2025a) yields estimates of population density.

We consider the following scenario

  • data include telemetry locations for a sample of animals,
  • deployment (attachment) of telemetry devices (e.g., radiocollars) is not modelled,
  • the spatial distribution of AC of telemetered animals is unknown,
  • detection histories (binary proximity or count) relate only to pre-marked telemetered individuals,
  • there is a history for each telemetered individual (all-zero if not detected), and
  • equivalent data (counts of detections) are collected for all individuals, whether marked and unmarked.

Implementation in secr 5.5.1

A detailed technical description is given in the vignette at https://www.otago.ac.nz/density/pdfs/secr-telemetry-marking.pdf. In outline:

  1. A capthist object is formed from the sightings of telemetered animals using the new telemetry type ‘marking’, the markocc attribute of its ‘traps’ is set to 0 for sighting occasions and 1 for the telemetry occasion(s), and sightings of unmarked animals are attached. The required capthist has one row for each telemetered animal, a ‘telemetryxy’ attribute that is a list with telemetry locations, and attribute ‘Tu’ for additional sightings of unmarked animals.
  2. A model is fitted as usual. The activity centres of the collared animals are integrated by Gauss-Hermite quadrature (details ‘telemetryint = “GH”’). The details ‘uselog’ and ‘safeLL’ are TRUE, to avoid numerical underflow with many telemetry fixes.
  3. The overdispersion ‘chat’ of the sightings is computed analytically from the fitted model (details ‘chatmethod = “analytic”’) and used to adjust the variances. This replaces the simulation of sightings (Efford and Hunter 2018) used for other mark–resight models. In secrdesign this is run.scenarios(..., chatnsim = -1) with chatmethod = "analytic" in fit.args$details.

As a check on the secr results, the same simulated data are also fitted by an independent maximum likelihood implementation in RTMB (Kristensen et al. 2016, Kristensen 2026) (see file ‘rtmb_marking.R’, listed in the Appendix). The RTMB implementation differs from the secr likelihood in modelling the total of sightings of unmarked animals as negative binomial rather than as Poisson with a variance scale factor.

Settings

These are intended to follow the 24 scenarios considered by Whittington et al. (2025a Appendix Table S2). A grid of 81 cameras spanning 90 units on a side (Whittington et al. 2025a p.4 stated 120 units) lies within a 150 x 150 square region (possibly 149 x 149 in Whittington et al. 2025b).

The same conditions are used for simulation and fitting.

Simulation code

The simulation function fnc.create.SMR.data from file ‘1a._gSMR_simStudy_functions_and_nimble_code.R’ of Whittington et al. (2025b) is used to generate each replicate capthist. It is copied here, along with the required function e2dist.

# See Whittington et al. (2025b)

# 0. Function e2dist ####
e2dist <- function (x, y) {  # Function from scrbook package to calculate the distance between locations in 2 matrices.
  i <- sort(rep(1:nrow(y), nrow(x)))
  dvec <- sqrt((x[, 1] - y[i, 1])^2 + (x[, 2] - y[i, 2])^2)
  matrix(dvec, nrow = nrow(x), ncol = nrow(y), byrow = F)
}

# 0.  Function to simulate data ####

fnc.create.SMR.data <- function (N = N, nMarked = nMarked, sigma = 1, lam0 = 0.5, K = 5,
                                 n.camera.row = 9, 
                                 xlims = c(1, 150), ylims = c(1, 150), xlim.R = c(30, 120), ylim.R = c(30, 120),
                                 nlocs = 100, plotSim = TRUE) 
  # N = True number of animals in the state-space
  # nMarked = number of animals to capture and mark
  # sigma = scale parameter for home range size
  # lam0 = encounter rate at home range centre for resighting
  # K = number of resighting (eg camera) occasions
  # n.camera.row = sqrt(total number of cameras)
  # xlims = min and max coordinates of easting for the state-space
  # ylims = min and max coordinates of northing for the state-space
  # xlim.R = min and max coorindates of easting for the study area
  # ylim.R = min and max coordinates of northing for the study area.
  # nMarked = Is the number of marked animals.  
  # nlocs = number of telemetry locations for each marked animal.  
  # plotSim = whether to plot state space, detectors, capture summary, and resighting summary
{
  ## Camera coordinates
  coor0 <- seq(xlim.R[1], xlim.R[2], length = n.camera.row)
  X.camera <- cbind(rep(coor0, each=length(coor0)),rep(coor0, times=length(coor0))) 
  
  J.camera <- nrow(X.camera)  
  # Capture Process: activity centres and marked animals
  enoughMarked = FALSE
  counter <- 0
  while(enoughMarked == FALSE & counter < 100){
    counter <- counter + 1
    sx <- runif(N, xlims[1], xlims[2])
    sy <- runif(N, ylims[1], ylims[2])
    sxy <- round(cbind(sx, sy))

    #### Capture data
    D <- e2dist(sxy, X.camera)
    
    K_capt = 20  #K
    lam_c <- lam0 * exp(-(D * D)/(2 * sigma * sigma))
    Y_c <- array(NA, c(N, J.camera, K_capt))   
    for (i in 1:N) {
      for (j in 1:J.camera) {
        Y_c[i, j, ] <- rpois(K_capt, lam_c[i, j]) # Detections of each individual
      }
    }
    # Select the first nMarked individuals captured
    for (k in 1:K_capt){
      marked.k <- apply(Y_c[ , , 1:k], 1, sum) 
      marked.01.k <- marked.k > 0 * 1
      if (sum(marked.01.k) >= nMarked){
        Y_c[ , , (k + 1):K_capt] <- 0
        break()
      }
    }
    indiv.captures <- apply(Y_c, 1, sum)              
    indiv.capt01 <- (indiv.captures > 0) * 1
    iMarked <- which(indiv.capt01 == 1)
    nDetected = length(iMarked)
    if(nDetected >= nMarked){
      enoughMarked = TRUE
    }
  } # End While loop
  if (enoughMarked == FALSE){
    stop('... change parameters - not enough animals within the study area for nMarked')
  }
  # select marked animals
  iKeep <- sample(1:N, size = nMarked, replace = FALSE, prob = indiv.captures / sum(indiv.captures))
  # Re-arrange so activity centres ordered by marked, then unmarked
  tmp1 <- sxy[iKeep, ]      # marked individuals
  tmp2 <- sxy[-c(iKeep), ]  # unmarked individuals
  # Arrange animals by marked, then unmarked
  sxy <- rbind(tmp1, tmp2)
  marked = ifelse(1:N <= nMarked, 1, 0)
  #  Resight data
  D <- e2dist(sxy, X.camera)
  lam <- lam0 * exp(-(D * D)/(2 * sigma * sigma))
  Y <- array(NA, c(N, J.camera, K))
  for (i in 1:N) {
    for (j in 1:J.camera) {
      Y[i, j, ] <- rpois(K, lam[i, j]) # true detections of each individual
    }
  }
  indiv.detections <- apply(Y, 1, sum)             
  indiv.detected <- (indiv.detections > 0) * 1
  nDet.jk <- apply(Y, c(2, 3), sum)   #  Sum of detections by Camera and Occasion
  det01.jk <- (nDet.jk > 0) * 1       #  Binomial detections
  nDet_population <- rowSums(nDet.jk)
  y01_population <- rowSums(det01.jk)
  Y.marked <- Y[marked == 1, , ]
  Y.marked.01 <- (Y.marked > 0) * 1  # i, j, k
  nDet_marked <- apply(Y.marked, c(1, 2), sum)  # individual x trap
  y01_marked <- apply(Y.marked.01, c(1, 2), sum) # matrix i x j for number of occasions with a detection

  telem_array <- array(0, dim = c(nMarked, nlocs, 2))
  if (nlocs > 0) {
    locs <- list()
    for (i in 1:nMarked) {
      telem_array[i, 1:nlocs, 1] <- rnorm(nlocs, sxy[i, 1], sigma)
      telem_array[i, 1:nlocs, 2] <- rnorm(nlocs, sxy[i, 2], sigma)
      
    }
  }
  if (plotSim == TRUE){
    par(mfrow = c(1,1))
    plot(sxy, col = 'red', pch = 19, xlim = xlims, ylim = ylims, asp = 1, xlab = 'X', ylab = 'Y',
         main = paste('Spatial Mark-Resight Simulated Data \n ',
                      ' lam0 =', lam0, ' sigma =', sigma, ' N =', N, sep = ' '))
    rect(xleft = xlims[1], xright = xlims[2], ybottom = ylims[1], ytop = ylims[2], col = 'gray80' )
    rect(xleft = xlim.R[1], xright = xlim.R[2], ybottom = ylim.R[1], ytop = ylim.R[2], col = 'gray70' )
    lapply(seq(xlims[1], xlims[2], by = 10), function(x) lines(c(x, x), c(ylims[1], ylims[2]), col = 'white'))
    lapply(seq(ylims[1], ylims[2], by = 10), function(x) lines( c(xlims[1], xlims[2]), c(x, x), col = 'white'))
    for(ttt in 1:nMarked){
      points(telem_array[ttt, ,1:2], col = ttt, cex = 0.4, pch = 1)
    }
    points(sxy, col = 'red', pch = 19, cex = 1.3)
    #points(X.trap, col='blue', pch = 1, cex = 1.2)
    points(X.camera, col = 'forestgreen', pch = '+', cex = 0.8)
    points(sxy[marked == 1, 1], sxy[marked == 1, 2], pch=19, col='purple', cex = 1.3)
    points(sxy[indiv.detected == 1, 1], sxy[indiv.detected == 1, 2], pch=1, col='yellow', cex = 0.5)
    legend(x = 0.7 * xlims[2], y = ylims[2], cex = 0.7, legend = c(  'Cameras', 'Home Range Centre', '  Marked', '  Detected Camera'),
           pch = c( 3, 19, 19, 1), col = c('forestgreen', 'red','purple', 'yellow' ), bg = 'gray80')
  }
  
  list(
      N               = N, 
      nMarked         = nMarked, 
      sigma           = sigma, 
      lam0            = lam0,
      sxy             = sxy, 
      Y               = Y,
      nDet_population = nDet_population,
      nDet_marked     = nDet_marked,
      y01_population  = y01_population,
      y01_marked      = y01_marked,
      telem_array     = telem_array, 
      X.camera        = X.camera,
      prop.detected   = mean(indiv.detected)
  )
  
}   # END OF FUNCTION  fnc.create.SMR.data

To use this function in secrdesign we define two further functions, one to cast the output from fnc.create.SMR.data as a capthist object and one to call the simulation function in a way that suits the ‘CH.function’ argument of secrdesign::run.scenarios.

# cast output from fnc.create.SMR.data as capthist object
asCH <- function(Wdata, detector = 'count', verify = FALSE) {
    with (Wdata, {
        nlocs <- dim(telem_array)[2]
        dimnames(X.camera)[[2]] <- c('x','y')
        trdf <- as.data.frame(X.camera)
        ch <- aperm(Y[1:nMarked,,,drop = FALSE], c(1,3,2))
        class(ch) <- 'capthist'
        traps(ch) <- read.traps(data = trdf, detector = detector)
        rownames(ch) <- 1:nMarked
        tu <- apply(Y[(nMarked+1):N,,], 2:3, sum, drop = FALSE)
        telemID <- data.frame(Session = rep(1,nMarked*nlocs), 
                              ID = rep(1:nMarked, each = nlocs),
                              Occasion = rep(1:nlocs, nMarked))
        telemmat <- matrix((aperm(telem_array, c(2,1,3))), ncol = 2)
        telemdf <- as.data.frame(telemmat)
        te <- read.telemetry(data = cbind(telemID, telemdf), verify = FALSE)
        ch <- addTelemetry(ch, te, type = 'marking', verify = FALSE)
        markocc(traps(ch)) <- c(rep(0,ncol(tu)),1)
        addSightings(ch, unmarked = tu, verify = verify)
    })
}
# function to call fnc.create.SMR.data and asCH from within run.scenarios
# this is an analogue of secr::sim.capthist
getWCH <- function (traps, popn, detectfn, detectpar, noccasions, 
                      ntelem, nocctelem, plotSim = FALSE) {
    # form capthist object from secrdesign 'CH.function' inputs 
    # but using Whittington et al. 2025b simulation code
    if (detectfn != 14 && detectfn != 'HHN') stop ("only for detectfn HHN")
    N            <- nrow(popn)
    nMarked      <- ntelem
    K.camera     <- noccasions
    sigma        <- detectpar$sigma
    lam0         <- detectpar$lambda0
    n.camera.row <- sqrt(nrow(traps))
    xlims        <- range(attr(popn, 'boundingbox')$x)
    ylims        <- range(attr(popn, 'boundingbox')$y)
    xlim.R       <- range(traps$x)
    ylim.R       <- range(traps$y)
    nlocs        <- nocctelem
    Wdata <- fnc.create.SMR.data(
        N = N, nMarked = nMarked,  K = K.camera, sigma = sigma, lam0 = lam0, 
        n.camera.row = n.camera.row, 
        xlims = xlims, ylims = ylims, xlim.R = xlim.R, ylim.R = ylim.R,  
        nlocs = nlocs, plotSim = plotSim)
    asCH (Wdata, detector = 'count', verify = FALSE)
}

This is the code in file ‘rtmb_marking.R’ used for the comparison with RTMB. It is an independent implementation of the one-stage likelihood for telemetry type ‘marking’ and is not run when this document is rendered. rtmb_extract_masks is the extractfn used with run.scenarios(fit = FALSE).

###############################################################################
## rtmb_marking.R
## One-stage maximum likelihood for telemetry-marking data with RTMB, as an independent
## implementation of the model fitted by secr::secr.fit for telemetry type 'marking'.
## Use as the 'extractfn' of secrdesign::run.scenarios(fit = FALSE, ...)
## (see function rtmb_extract at the end of this file).
##
## Model (count detectors, homogeneous density, hazard half-normal, uniform prior for
## the activity centres of the collared animals):
##   * collared animal i: identified cue counts Poisson(q U_k lambda_k(s_i)); n_i telemetry
##     fixes bivariate normal about s_i with the same sigma as the detection function; the
##     activity centre s_i is integrated out by Gauss-Hermite quadrature about the mean fix
##     (or summed over the mask if the animal has no fixes);
##   * unmarked cues: total C_u negative binomial with mean mu = D J1 - sum_i E_i[L(s_i)],
##     where J1 = integral of the cue rate L(x) over the mask and E_i is the posterior mean
##     given animal i's own data, and variance c-hat * mu (compound-Poisson; Poisson or
##     fixed number of animals; the posterior variance of the collared animals' cues is
##     included); c-hat is estimated in a first pass and then held fixed;
##   * unidentified marked cues Tm (optional): Poisson((1 - q) U_k sum_i E_i[lambda_k]).
## Differences from secr: the unmarked total is negative binomial rather than Poisson
## with a variance scale factor (point estimates of D differ by 0.4-2%), and there is no
## density model.
##
## Requires packages RTMB and secr (exported functions only). Units: mask area in
## hectares gives density per hectare.
###############################################################################

## Gauss-Hermite nodes and weights for a standard normal (probabilists'), n nodes
gh_std_normal <- function (n) {
    J <- matrix(0, n, n)
    if (n > 1) for (i in 1:(n - 1)) J[i, i + 1] <- J[i + 1, i] <- sqrt(i)
    e <- eigen(J, symmetric = TRUE)
    list(z = e$values, w = e$vectors[1, ]^2)
}

## Fit to a capthist of telemetry type 'marking'.
## distribution: "binomial" (fixed N) or "poisson". Returns a list, or NULL if the fit failed.
fit_rtmb_marking <- function (capthist, mask, distribution = c("binomial", "poisson"),
                              ngh = 7, trace = FALSE) {
    ## RTMB must be attached (not just loaded): its automatic-differentiation versions of
    ## functions such as plogis and lgamma are used by the likelihood below
    suppressPackageStartupMessages(require(RTMB))
    distribution <- match.arg(distribution)
    ptm <- proc.time()

    ## 1. Data --------------------------------------------------------------
    traps <- secr::traps(capthist)
    ## number of sighting detectors: all rows of 'traps' except the notional telemetry detector
    ## (detector() has one element per occasion, not per detector)
    K0    <- nrow(traps) - any(secr::detector(traps) == "telemetry")
    S     <- sum(secr::markocc(traps) == 0)                   # sighting occasions
    CH0   <- apply(capthist[, 1:S, 1:K0, drop = FALSE], c(1, 3), sum)   # n x K0 identified cues
    traps_xy <- as.matrix(traps[1:K0, ])
    u     <- secr::usage(traps)
    usage <- if (is.null(u)) matrix(1, K0, S) else as.matrix(u)[1:K0, 1:S, drop = FALSE]
    U0    <- rowSums(usage)
    keep  <- U0 > 0                      # unused detectors carry no information
    K     <- sum(keep)
    CH    <- CH0[, keep, drop = FALSE]
    U     <- U0[keep]
    trap_xy <- traps_xy[keep, , drop = FALSE]
    n     <- nrow(CH)

    mask_xy <- as.matrix(mask)
    a       <- attr(mask, "area")
    M       <- nrow(mask_xy)
    A_mask  <- M * a

    Tu  <- attr(capthist, "Tu")
    if (is.null(Tu)) stop("capthist has no Tu attribute")
    C_u <- sum(Tu)
    Tm  <- attr(capthist, "Tm")
    Tm_k <- if (is.null(Tm)) rep(0, K) else rowSums(as.matrix(Tm)[1:K0, 1:S, drop = FALSE])[keep]
    has_Tm <- sum(Tm_k) > 0

    telem <- secr::telemetryxy(capthist)
    has_tel <- if (length(telem) == n) vapply(seq_len(n), function(i)
        !is.null(telem[[i]]) && nrow(telem[[i]]) > 0, logical(1)) else rep(FALSE, n)
    tel_i <- which(has_tel); non_i <- which(!has_tel)
    telinfo <- lapply(tel_i, function(i) {
        tx <- as.matrix(telem[[i]]); tb <- colMeans(tx)
        list(tb = tb, nl = nrow(tx), ssd = sum(sweep(tx, 2, tb)^2)) })

    gh <- gh_std_normal(ngh)
    zz <- as.matrix(expand.grid(z1 = gh$z, z2 = gh$z))
    logw_gh <- log(as.vector(outer(gh$w, gh$w)))
    G  <- nrow(zz)

    d2m <- outer(mask_xy[, 1], trap_xy[, 1], "-")^2 + outer(mask_xy[, 2], trap_xy[, 2], "-")^2  # M x K
    Cm  <- matrix(rep(trap_xy[, 1], each = G), G, K)
    Cy  <- matrix(rep(trap_xy[, 2], each = G), G, K)
    lgY <- rowSums(lgamma(CH + 1))
    dat <- list(CH = CH, U = U, K = K, S = S, n = n, M = M, a = a, A_mask = A_mask,
                d2m = d2m, Cm = Cm, Cy = Cy, G = G, z1 = zz[, 1], z2 = zz[, 2], logw = logw_gh,
                tel_i = tel_i, non_i = non_i, telinfo = telinfo,
                YlogU = as.vector(CH %*% log(U)), sumY = rowSums(CH), lgY = lgY,
                Tm_k = Tm_k, Tm_pos = which(Tm_k > 0), lgTm = sum(lgamma(Tm_k + 1)), has_Tm = has_Tm,
                C_u = C_u, distribution = distribution, chat_on_tape = TRUE, chat = NA_real_)

    ## 2. Starting values ---------------------------------------------------
    s_init <- t(vapply(seq_len(n), function(i) {
        if (has_tel[i]) telinfo[[match(i, tel_i)]]$tb
        else if (any(CH[i, ] > 0)) colMeans(trap_xy[CH[i, ] > 0, , drop = FALSE])
        else colMeans(trap_xy)
    }, numeric(2)))
    sig0 <- if (any(has_tel)) {
        sqrt(sum(vapply(telinfo, function(x) x$ssd, 0)) / (2 * sum(vapply(telinfo, function(x) x$nl, 0))))
    } else secr::RPSV(capthist, CC = TRUE)
    Lam_at <- function(xy, lam0, sig)
        rowSums(sapply(1:K, function(k)
            U[k] * lam0 * exp(-((xy[, 1] - trap_xy[k, 1])^2 + (xy[, 2] - trap_xy[k, 2])^2) / (2 * sig^2))))
    lam00 <- (sum(CH) + sum(Tm_k)) / max(sum(Lam_at(s_init, 1, sig0)), 1e-12)
    lam00 <- min(max(lam00, 1e-6), 10)
    I10   <- sum(Lam_at(mask_xy, lam00, sig0)) * a
    Du0   <- max(C_u, 1) / I10
    q0    <- if (has_Tm) min(max(sum(CH) / (sum(CH) + sum(Tm_k)), 0.1), 0.9) else 1

    pars <- list(log_Du = log(Du0), log_lambda0 = log(lam00), log_sigma = log(sig0),
                 logit_q = qlogis(q0))
    map  <- if (has_Tm) list() else list(logit_q = factor(NA))

    smooth_pos <- function(x, eps) 0.5 * (x + sqrt(x^2 + eps^2))
    lse <- function(x) { m <- max(x); m + log(sum(exp(x - m))) }

    ## 3. Negative log-likelihood ------------------------------------------
    nll_joint <- function (pars) {
        Du      <- exp(pars$log_Du)
        lambda0 <- exp(pars$log_lambda0)
        sigma   <- exp(pars$log_sigma)
        q       <- if (dat$has_Tm) plogis(pars$logit_q) else 1
        two_s2  <- 2 * sigma^2
        K <- dat$K; U <- dat$U

        loglam_m <- pars$log_lambda0 - dat$d2m / two_s2
        lam_m    <- exp(loglam_m)
        Lm  <- (lam_m %*% U)[, 1]                  # cue rate (all occasions) at each mask cell
        J1  <- sum(Lm) * dat$a
        J2  <- sum(Lm^2) * dat$a

        nll <- 0
        SumEL <- 0; Vs <- 0
        Elam  <- rep(0, K)                          # sum_i E_i[lambda_k(s_i)]

        ## collared animals without telemetry: sum over mask cells
        nu <- length(dat$non_i)
        if (nu > 0) {
            Y  <- dat$CH[dat$non_i, , drop = FALSE]
            cu <- dat$YlogU[dat$non_i] + dat$sumY[dat$non_i] * log(q) - dat$lgY[dat$non_i]
            F  <- Y %*% t(loglam_m) + cu - rep(q * Lm, each = nu)     # nu x M
            ls <- apply(F, 1, lse)
            nll <- nll - (sum(ls) - nu * log(dat$M))
            W  <- exp(F - ls)
            EL  <- (W %*% Lm)[, 1]
            EL2 <- (W %*% Lm^2)[, 1]
            SumEL <- SumEL + sum(EL)
            Vs    <- Vs + sum(EL2 - EL^2)
            Elam  <- Elam + (t(colSums(W)) %*% lam_m)[1, ]
        }

        ## collared animals with telemetry: Gauss-Hermite about the mean fix
        for (j in seq_along(dat$tel_i)) {
            i  <- dat$tel_i[j]; ti <- dat$telinfo[[j]]
            sdj <- sigma / sqrt(ti$nl)
            xg <- ti$tb[1] + sdj * dat$z1
            yg <- ti$tb[2] + sdj * dat$z2
            d2 <- (matrix(rep(xg, K), dat$G, K) - dat$Cm)^2 + (matrix(rep(yg, K), dat$G, K) - dat$Cy)^2
            loglam <- pars$log_lambda0 - d2 / two_s2
            lam    <- exp(loglam)
            Lg     <- (lam %*% U)[, 1]
            cu <- dat$YlogU[i] + dat$sumY[i] * log(q) - dat$lgY[i]
            F  <- (loglam %*% dat$CH[i, ])[, 1] + cu - q * Lg + dat$logw
            ls <- lse(F)
            tel <- -ti$nl * log(2 * pi * sigma^2) - ti$ssd / two_s2 + log(2 * pi * sigma^2 / ti$nl)
            nll <- nll - (tel - log(dat$A_mask) + ls)
            w   <- exp(F - ls)
            EL  <- sum(w * Lg); EL2 <- sum(w * Lg^2)
            SumEL <- SumEL + EL
            Vs    <- Vs + (EL2 - EL^2)
            Elam  <- Elam + (t(w) %*% lam)[1, ]
        }

        ## unidentified marked cues, by detector
        if (dat$has_Tm) {
            mean_k <- (1 - q) * U * Elam
            pos <- dat$Tm_pos
            nll <- nll - (sum(dat$Tm_k[pos] * log(mean_k[pos] + 1e-30)) - sum(mean_k) - dat$lgTm)
        }

        ## total density = unmarked + marked contribution
        D  <- Du + SumEL / J1

        ## overdispersion of the unmarked total, averaged over deployment
        mu <- Du * J1
        if (dat$distribution == "binomial") {
            r <- D * (J2 - J1^2 / dat$A_mask) / mu
        } else {
            r <- D * J2 / mu
        }
        chat <- if (dat$chat_on_tape) 1 + smooth_pos(r + Vs / mu, 1e-3) else dat$chat

        C  <- dat$C_u
        kd <- mu / (chat - 1)
        nll <- nll - (lgamma(C + kd) - lgamma(C + 1) - lgamma(kd) +
                      kd * log(kd / (kd + mu)) + C * log(mu / (kd + mu)))

        RTMB::REPORT(chat); RTMB::REPORT(mu); RTMB::REPORT(Vs); RTMB::REPORT(SumEL)
        RTMB::ADREPORT(D); RTMB::ADREPORT(lambda0); RTMB::ADREPORT(sigma)
        if (dat$has_Tm) RTMB::ADREPORT(q)
        nll
    }

    fit_once <- function (start) {
        obj <- RTMB::MakeADFun(nll_joint, start, map = map, silent = !trace)
        opt <- tryCatch(nlminb(obj$par, obj$fn, obj$gr,
                               control = list(iter.max = 500, eval.max = 1000)),
                        error = function(e) e)
        list(obj = obj, opt = opt)
    }

    ## 4. Two passes: c-hat on the tape, then held fixed ---------------------
    f1 <- fit_once(pars)
    if (inherits(f1$opt, "error")) return(NULL)
    chat_hat <- f1$obj$report(f1$obj$env$last.par.best)$chat
    dat$chat_on_tape <- FALSE
    dat$chat <- as.numeric(chat_hat)
    f <- fit_once(f1$obj$env$parList(f1$opt$par))
    if (inherits(f$opt, "error") || f$opt$convergence != 0) return(NULL)

    sdr <- RTMB::sdreport(f$obj)
    list(estimates = summary(sdr, select = "report"),
         chat      = dat$chat,
         has_Tm    = has_Tm,
         proctime  = unname((proc.time() - ptm)[3]))
}

###############################################################################
## extractfn for secrdesign::run.scenarios(fit = FALSE, ...)
##
## run.scenarios calls extractfn(capthist, ...) for each simulated capthist when
## fit = FALSE; the additional named arguments of run.scenarios are passed on, so supply
## the mask (and optionally 'distribution') there, e.g.
##   run.scenarios(nrepl, scenario, fit = FALSE, extractfn = rtmb_extract,
##                 mask = msk, distribution = "binomial", ...)
## Returns a data frame with one row per parameter (D, lambda0, sigma, plus pID if Tm are
## present) and columns estimate, SE.estimate, lcl, ucl, in the form returned for a
## secr fit by predict(), so that secrdesign::estimateSummary applies to the output.
## Intervals are log-normal as in secr. Attributes: proctime (seconds), chat.
## A failed fit gives NA estimates.
###############################################################################
rtmb_extract <- function (capthist, mask, distribution = "binomial", ...) {
    fit <- try(fit_rtmb_marking(capthist, mask, distribution), silent = TRUE)
    rows <- c("D", "lambda0", "sigma")
    if (inherits(fit, "try-error") || is.null(fit)) {
        out <- data.frame(estimate = NA_real_, SE.estimate = NA_real_, lcl = NA_real_, ucl = NA_real_,
                          row.names = "D")
        out <- out[rep(1, 3), ]
        rownames(out) <- rows
        attr(out, "proctime") <- NA_real_
        attr(out, "chat") <- NA_real_
        return(out)
    }
    est <- fit$estimates
    if (fit$has_Tm) rows <- c(rows, "q")
    est <- est[match(rows, rownames(est)), , drop = FALSE]
    z   <- qnorm(0.975)
    ## log-normal interval as secr: w = exp(z * sqrt(log(1 + (SE/estimate)^2)))
    w   <- exp(z * sqrt(log(1 + (est[, 2] / est[, 1])^2)))
    out <- data.frame(estimate = est[, 1], SE.estimate = est[, 2],
                      lcl = est[, 1] / w, ucl = est[, 1] * w, row.names = rows)
    if (fit$has_Tm) rownames(out)[rownames(out) == "q"] <- "pID"
    attr(out, "proctime") <- fit$proctime
    attr(out, "chat") <- fit$chat
    out
}
